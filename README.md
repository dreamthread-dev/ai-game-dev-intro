# ai-game-dev-intro

DREAM THREAD のブログ連載「AIゲーム開発入門」の作例。
ボタン1つで遊ぶ、壁を蹴って登る2Dアクションゲーム。

## 動かし方

1. [Godot](https://godotengine.org/) 4.7.2 を公式サイトからダウンロードする
2. このリポジトリをクローンし、Godot で `project.godot` を開く
3. F5 で実行する
